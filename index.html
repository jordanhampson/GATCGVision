Connection trouble?

Tables use direct browser-to-browser connections. Strict home routers, mobile data and work or school networks can block them. A relay (TURN) server fixes that. Each player can run this check on their own network.


      
Relay server

      
Free option: make an account at metered.ca (Open Relay, advertised as 20 GB a month free), then copy the server address, username and password it gives you. For two players, a working relay on either side is enough, so if you are hosting, you having it usually lets strict-network players join you. Saved on this device only.
